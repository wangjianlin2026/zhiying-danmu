智映AI-小智AI弹幕自动回复系统 源码版
====================================

1. 本目录是可直接修改的 Python 源码，不是打包后的 EXE。
2. 修改前建议先复制一份整个源码目录做备份。
3. 运行环境：Windows + Python 3.12。
4. 首次运行前安装依赖：
   pip install -r requirements.txt
5. 双击“启动源码版.bat”运行；需要看报错时双击“调试启动.bat”。
6. 数据与配置保存在本目录的 data 文件夹。
7. 修改源代码后需要重新打包，才能生成新的安装版。
